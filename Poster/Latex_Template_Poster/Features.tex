\block{Overview of the ML Model}{
	\Large
	\textbf{Employed Features}
	\vspace{0.7cm}
	\begin{itemize}
		\item Atomically partitioned features dependent on the geometry, electron density, and individual contributions to the total energy.
		\item Mulliken partitioning has been used for the generation of atomistic features.
	\end{itemize}
\vspace{0.7cm}
\textbf{The Hessian Matrix}

\begin{minipage}{0.6\linewidth}
\begin{itemize}
	\item The elements of the Hessian are second derivatives either with respect to the coordinates of a single atom or of two atoms.
	\item For the machine learning (ML) model, we distinguish between the diagonal blocks (blue, same atoms) and off--diagonal blocks (red, different atoms).
\end{itemize}
\end{minipage}%
%\vspace{1.5cm}
\begin{minipage}{0.4\linewidth}
	\centering
	$\dfrac{\partial^2 E }{\partial \alpha_\mathrm{A} \partial \beta_\mathrm{A}}$ :~\includegraphics[width=30pt]{Graphics/blauerBlock.pdf}~~ $\dfrac{\partial^2 E }{\partial \alpha_\mathrm{A} \partial \beta_\mathrm{B}}$:~\includegraphics[width=30pt]{Graphics/roterBlock.pdf} $\alpha,\beta \in {x,y,z}$
	\adjincludegraphics[height=10cm,trim={{.1\width} {.05\height} {.1\width} {.05\height}},clip]{Graphics/MatrixHeatmap.eps}
	%\includegraphics[width=0.8\linewidth]{Graphics/MatrixHeatmap.eps}
\end{minipage}

\textbf{Connecting Features and Targets}
\vspace{0.7cm}
\begin{itemize}
	\item The feature vector is either build from the quantities of one or two atoms.
	\item For ML modeling, a fixed feature vector length is necessary, hence two separate models are used which rely on ensemble--based decision tree methods\autocite{scikit-learn}.
	\item The features and targets are provided for each $3 \times 3$ block in a model--specific orientation.
\end{itemize}
